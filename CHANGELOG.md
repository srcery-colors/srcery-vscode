# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

Historical dates are taken from Git tags. Dates are omitted where no matching tag exists.

## [Unreleased]

<!-- Planned for 0.4.0. Set the release version, date, and comparison links when releasing. -->

### Added

- Scope Inspector documentation for reporting highlighting issues ([#45]).
- Biome and theme validation, CI packaging, and an explicit VSIX file allowlist ([#58], [#61]).

### Changed

- Align syntax highlighting with the canonical Srcery TextMate theme and update the workbench palette ([#44]).

### Fixed

- Update the Marketplace icon ([#49]).

## [0.3.5]

### Added

- Package lockfile.

### Fixed

- Title bar colors ([#2]).

## [0.3.4] - 2019-10-24

### Added

- Selection, word highlight, find match, and hover highlight colors.

### Changed

- Make the selection background opaque.

## [0.3.3] - 2018-12-26

### Changed

- Improve the active list foreground's readability, both with and without keyboard focus.
- Complete editor group and tab behavior.

## [0.3.2] - 2018-12-24

### Added

- Tab colors to emphasize the active tab.

## [0.3.1] - 2018-12-23

### Changed

- Darken the tab line to complete the focus effect.

## [0.3.0] - 2018-12-23

### Added

- Line number highlights.

### Changed

- Darken the panel, activity bar, and sidebar relative to the editor to emphasize the editor.
- Lighten the selection background to a greenish color.
- Adjust existing colors for readability.

## [0.2.3] - 2018-12-16

### Added

- Colors for base UI elements, scrollbars, inputs, dropdowns, text, and buttons.

### Changed

- Improve list hover visibility and distinguish the current selection from other list items.

## [0.2.2] - 2018-12-07

### Added

- Attribution for the starter theme.
- An invitation to report issues.

### Changed

- Improve README presentation for the Marketplace and GitHub with badges.

## [0.2.1] - 2018-12-07

### Added

- Icon and banner attributes for the Marketplace extension page.

## [0.2.0]

### Changed

- Bump the minor version to avoid conflicts with tags imported from gagbo/srcery-vscode.

### Fixed

- Package metadata URLs.

## [0.1.0] - 2018-12-05

### Added

- Initial release from gagbo/srcery-vscode.
